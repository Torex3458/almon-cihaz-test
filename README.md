# almon-cihaz-test

almon.ai'nin farklı cihazlarda görünüm testi: yayındaki sayfalar gerçek Mac Safari'de (iki ekran boyu) ve iPhone / iPad simülatöründe Safari ile açılır, ekran görüntüsü ve kısa ölçüm özeti (sayfa yüksekliği, yatay taşma, sayfa hataları) çalıştırmanın çıktısı olarak saklanır. Depoda site kodu yoktur; yalnız yayındaki adresi açan test betikleri vardır. Çalıştırma elle tetiklenir (Actions → cihaz → Run workflow).
